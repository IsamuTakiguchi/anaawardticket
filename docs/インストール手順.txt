============================================================
 ANAマイルナビ — インストール手順（Chrome / Microsoft Edge）
============================================================

ANA特典航空券の空席を、期間・曜日・復路の日数・座席クラスで
まとめて自動検索する拡張機能です。
Chrome ウェブストアには公開していないため、以下の手順で
「フォルダから直接読み込む」方式でインストールします。

------------------------------------------------------------
■ 事前準備
------------------------------------------------------------
・パソコン版の Google Chrome（または Microsoft Edge）を使ってください。
  スマートフォンでは利用できません。
・このZIPファイルを、消さない場所（例：ドキュメント）に置いてください。

------------------------------------------------------------
■ インストール手順
------------------------------------------------------------
1. このZIPファイルを右クリック →「すべて展開」を選び、展開します。
   →「ANAマイルナビ」という名前のフォルダができます。
   ※このフォルダは消したり移動したりしないでください。
     Chromeは毎回このフォルダを読みに行くため、消すと動かなくなります。

2. Chrome を開き、アドレス欄に次を入力して Enter：
        chrome://extensions
   （Edge の場合は  edge://extensions ）

3. 画面右上の「デベロッパーモード」のスイッチを【オン】にします。

4. 左上に出てくる
   「パッケージ化されていない拡張機能を読み込む」ボタンを押します。

5. 手順1で展開した「ANAマイルナビ」フォルダを選択します。
   （フォルダの中に manifest.json というファイルが入っているのが目印です）

6. 一覧に「ANAマイルナビ」が表示されれば完了です。
   画面右上のパズルのアイコンから、ピン留めしておくと便利です。

------------------------------------------------------------
■ 使い方
------------------------------------------------------------
1. ANA公式サイトにログインします。
2. 国際線特典航空券の「往復の空席照会」を1回行い、
   結果一覧のページを開いた状態にします。
3. ツールバーの「ANAマイルナビ」アイコンを押して、
   サイドパネルを開きます。
4. 出発空港・目的地・期間・曜日・復路の日数・座席クラスを設定し、
   「検索開始」を押します。
5. 各日付の照会が自動で順番に行われ、空席のある便が
   一覧に追記されます（必要マイル・燃油サーチャージも表示）。
   サイドパネルは開いたままにしてください。

------------------------------------------------------------
■ うまく動かないとき
------------------------------------------------------------
・「検索開始」を押しても進まない場合は、ANAのページを開き直し、
  もう一度サイドパネルから検索を開始してください。
・Chrome起動時に「デベロッパーモードの拡張機能…」という確認が
  出ることがありますが、正常です（そのまま使えます）。
・拡張機能を更新したいときは、chrome://extensions の
  「ANAマイルナビ」の更新（リロード）ボタンを押してください。
