# プライバシーポリシー（ANAマイルナビ）

最終更新日：2026年6月5日

「ANAマイルナビ」（以下「本拡張機能」）は、利用者のプライバシーを尊重し、
個人情報を収集・送信しないことを基本方針としています。

## 1. 収集する情報
本拡張機能は、利用者の氏名・メールアドレス・ANAマイレージクラブ番号・
パスワード等の認証情報を含む、いかなる個人情報も収集・保存・送信しません。

## 2. 動作の仕組み
本拡張機能は、利用者ご自身がブラウザで既にログインしているANA公式サイトの
セッションを利用して動作します。ログイン認証は利用者とANAの間で完結しており、
本拡張機能が認証情報に関与することはありません。

## 3. データの保存
入力した検索条件および検索結果（便名・必要マイル・燃油サーチャージ・空席状況など）は、
ブラウザの拡張機能ローカルストレージ（chrome.storage.local）にのみ保存されます。
これらのデータが利用者の端末の外部へ送信されることはありません。

## 4. 外部送信・第三者提供
本拡張機能は、収集・表示する情報を外部サーバーへ送信せず、第三者へ提供・販売しません。
広告・解析（トラッキング）目的のための情報収集も行いません。

## 5. 権限の利用目的
本拡張機能が要求する各権限（storage / sidePanel / tabs / scripting および
ANAサイトへのホスト権限）は、ANA公式サイト上での空席照会の自動化と結果の表示の
ためにのみ使用されます。ANA以外のサイトでは動作しません。

## 6. 第三者との関係
本拡張機能はANA（全日本空輸株式会社）の公式ツールではなく、ANAおよびその関連会社とは
一切関係ありません。

## 7. お問い合わせ
本ポリシーに関するお問い合わせは、配布元（GitHubリポジトリ等）の連絡先までお願いします。

## 8. 改定
本ポリシーは予告なく改定されることがあります。重要な変更がある場合は、本ページにて
告知します。
