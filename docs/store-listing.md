## 2. 詳細な説明（Description｜最大16,000文字）

```
ANAマイルナビは、ANAマイレージクラブの特典航空券（国内線・国際線）の空席を、
1件ずつ手作業で照会する手間をなくし、条件に合う往復の組み合わせをまとめて
自動で検索・一覧化するChrome拡張機能です。

■ こんな方へ
・「この期間のどこかで特典航空券を取りたい」が、日付の組み合わせが多すぎて探せない
・出発日を少しずつずらして、空いている便を片っ端から確認したい
・ANA運航便か、スターアライアンス提携便かを区別して比較したい
・必要マイルや燃油サーチャージ（税金・料金等）を一覧で見比べたい

■ 主な機能
・出発空港・目的地（複数指定可）・検索期間・出発曜日・復路便（出発の何日後か）・
　座席クラス（複数選択可）を条件に設定
・条件に合う往復の全組み合わせを、人にやさしい間隔をあけて順番に自動検索
・空席のある便を、出発地→目的地・往復の日付・便名・運航会社・座席クラス・
　必要マイル・税金/燃油サーチャージの一覧に整理
・必要マイルや料金での並べ替え、ANAのみ/提携のみ・座席クラス・上限マイル・
　空席待ち除外でのフィルタ
・結果のCSV出力（Excelでそのまま開けるUTF-8 BOM付き）
・進捗・残り時間の表示、一時停止・再開・中止、失敗分の再検索

■ 使い方
1. ANAの公式サイトにログインし、特典航空券の空席照会ページを開きます。
2. 拡張機能のサイドパネルを開き、出発空港・目的地・期間などの条件を入力します。
3. 「検索開始」を押すと、ANAのページ上で各日付の照会が自動で順番に行われ、
　 結果がサイドパネルの一覧に追記されていきます。

■ 安全性・プライバシーについて
・本拡張機能は、お客様ご自身がブラウザでログイン済みのANAセッションを利用して
　動作します。ログインID・パスワードなどの認証情報を取得・保存・送信することは
　一切ありません。
・検索結果は、お使いのブラウザ内（ローカル）にのみ保存されます。外部サーバーへ
　送信することはありません。
・収集した情報を第三者に提供・販売することはありません。

■ ご利用上の注意（必ずお読みください）
・本拡張機能はANAの公式ツールではありません。ANAおよびその関連会社とは一切関係
　ありません。
・自動での空席照会は、ANAサイトの利用規約に抵触する可能性があります。ご利用は
　お客様ご自身の責任において、個人利用・低頻度・控えめな間隔でお願いします。
・ANAサイトの仕様変更により、予告なく動作しなくなる場合があります。
・短時間に大量の検索を行うと、ANA側でアクセス制限がかかる場合があります。
　本拡張機能は人にやさしい間隔をあけて検索しますが、過度な利用はお控えください。
```

## 3. プライバシー（審査で必須）

### 単一用途の説明（Single purpose）
```
ANA公式サイト上で、利用者本人のログイン済みセッションを用いてANA特典航空券の
空席照会を自動化し、条件に合う往復便の空席・必要マイル・燃油サーチャージなどを
一覧に整理して表示することを唯一の目的とします。
```

### 各権限の根拠（Permission justification）

| 権限 | 入力する根拠（理由） |
|---|---|
| `storage` | 検索条件・検索結果・進捗をブラウザ内（ローカル）に保存し、サイドパネルを閉じても復元できるようにするため。外部送信は行いません。 |
| `sidePanel` | 検索条件の入力と結果一覧を表示するUIを、ANAのタブと並べて表示し続けるため。ポップアップはフォーカスを失うと閉じてしまい、長時間のスイープ検索に不向きなためサイドパネルを使用します。 |
| `tabs` | 開いているANA予約サイト（aswbe.ana.co.jp / aswbe-i.ana.co.jp）のタブを特定し、そのタブに対してのみ検索の実行指示を送るため。閲覧履歴の取得には使用しません。 |
| `scripting` | ANAの空席照会結果ページのDOMから、便名・必要マイル・燃油サーチャージ・空席状況などの公開情報を読み取って一覧化するため。 |
| ホスト権限 `https://aswbe.ana.co.jp/*`, `https://*.ana.co.jp/*` | ANA予約サイト上でのみ動作し、空席照会の自動入力と結果の読み取りを行うため。ANA以外のサイトでは一切動作しません。 |

### リモートコードの使用
```
いいえ（使用しません）。すべてのコードは拡張機能パッケージに同梱されています。
```

### データ使用の開示（Data usage）
- 収集・送信する個人情報：**なし**
- 以下のすべてにチェックを入れて宣言できます：
  - ✅ ユーザーデータを第三者に販売しない
  - ✅ 承認された用途以外でユーザーデータを使用・転送しない
  - ✅ 信用調査・融資目的でユーザーデータを使用・転送しない

> 補足：本拡張機能は、ANAサイトに表示される空席情報を読み取って利用者のブラウザ内に
> 保存・表示するのみで、いかなるデータも外部サーバーへ送信しません。

### プライバシーポリシーURL
`docs/privacy-policy.md` の内容を、GitHub Pages や任意の公開URLに掲載し、そのURLを入力してください。
（GitHubリポジトリ上のファイルURLでも可）
